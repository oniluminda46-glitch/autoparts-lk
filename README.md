\# AutoPartsLK - 4-Part Full-Stack Assessment



This repository contains the 4 projects completed for the assessment:



\### 1. `01-go-basics`

\- Golang foundational syntax, structs, and slice operations.



\### 2. `02-go-gin-api`

\- Standalone RESTful API built with the Gin Web Framework.



\### 3. `03-nextjs-basics`

\- Next.js 15 concepts: App router, React hooks, and Tailwind CSS.



\### 4. `04-fullstack-autoparts` (Main Marketplace App)

\- Full-stack marketplace application based on the AutoPartsLK PRD.

\- Backend: Go (Gin) REST API running on port 8080.

\- Frontend: Next.js responsive UI running on port 3000.
